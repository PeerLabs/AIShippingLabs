# AIShippingLabs

AI Shipping Labs Course

## Course Structure

This is a 9-week program designed to take us from LLM basics to production-ready AI applications.

### Week 1: Foundation - LLMs, RAG and Search

Set up our environment, learn LLM fundamentals, and build our first RAG system. Understand how LLMs work and how to augment them with retrieval.

### Week 2: Advanced RAG and Buffer Week

Finish preparing the environment and explore advanced RAG techniques. This week provides flexibility for everyone to get up to speed.

### Week 3: AI Agents

Move beyond fixed RAG flows to intelligent agents that decide when and how to use tools. We'll build agents from scratch to understand what happens inside frameworks, then learn agent frameworks like PydanticAI and the Model Context Protocol.

Several frameworks are included as optional materials based on student requests:

- LangChain and LangGraph (popular, but PydanticAI remains the primary focus)
- Google ADK (Agent Development Kit)
- CrewAI
- OpenAI Agents SDK

### Week 4: Testing and Multi-Agent Systems

Learn to test agents systematically. Convert Jupyter notebooks to Python projects, write unit tests, track usage and costs, use LLMs as judges, and explore multi-agent patterns including linear execution, planner-executor, and orchestrator patterns.

### Week 5: Monitoring and Observability

Set up observability for AI systems. Learn logging, tracing, and monitoring with Pydantic Logfire, OpenTelemetry, Jaeger, and Grafana. Also covers DIY logging approaches and other observability platforms.

### Week 6: Evaluation and Improvement

Generate evaluation data and validate agents. Use manual log evaluation, synthetic data generation, retrieval evaluation, LLM judges, prompt optimization with the evaluator pattern, and selecting chunking approaches with evals.

### Week 7: Project Work and Bonus

Focus on our project work. Optional materials on guardrails to keep our agents safe and deployment options.

### Week 8: Project Work and Cases

Continue working on projects and explore advanced use cases including coding agents, deep research agents, and more.

### Week 9: Demo

Present your project demo and participate in peer review.

## Technologies We'll Use

- **LLM APIs:** OpenAI, Anthropic, Groq, Gemini, Z.ai, Amazon Bedrock
- **Vector databases:** Qdrant, Elasticsearch
- **Agent frameworks:** PydanticAI, OpenAI Agents SDK, ToyAIKit, LangChain
- **Evaluation tools:** synthetic data, LLM judges
- **Monitoring:** Logfire, OpenTelemetry, Jaeger, Grafana
- **Deployment:** Streamlit, Render, AWS

## Prerequisites

- Basic Python programming knowledge
- Familiarity with command line
- Curiosity to learn and build

We don't need prior AI or ML experience. We'll start from the fundamentals and build up progressively.

## Course Scope

This course focuses on AI engineering - integrating AI and agents into products. We treat LLMs as a black box that accepts requests and returns responses, using pre-trained models via API.

The course does not cover:

- Fine-tuning open source models
- Running models locally
- LLM internals and architecture

We focus on practical application using existing models rather than model training and internal architecture.
